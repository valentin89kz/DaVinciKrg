# Художественная школа DA VINCI — лендинг

Одностраничный сайт художественной школы DA VINCI (Караганда) — курс академического
рисунка для подготовки к поступлению в художественные, архитектурные и дизайнерские вузы.

**Статус: черновик-макет.** Часть изображений — временные заглушки, см. раздел ниже.

## Состав

```text
index.html      — весь сайт одним файлом
img/            — изображения (14 файлов)
.stitch/        — исходники проекта для Google Stitch
  SITE.md       — конституция проекта: факты, аудитория, карта сайта, бэклог
  DESIGN.md     — дизайн-система: палитра, типографика, компоненты
  next-prompt.md— задача следующей итерации (мобильная версия)
  metadata.json — идентификаторы проекта и экрана в Stitch
```

## Что уже есть

12 секций: первый экран, статистика, вузы поступления, боли абитуриента, программа курса,
этапы подготовки, преподаватели, работы учеников, стоимость и расписание, отзывы, FAQ,
форма заявки и подвал.

Данные школы в разметке настоящие: адрес (ул. Бухар-Жырау, 55), телефон, состав
преподавателей, цена 27 000 ₸, расписание двух групп, статистика поступлений по семи вузам.

Дизайн-система «Academic Atelier»: тёплая бумага `#FAF7F2`, графит `#1C1A18`,
сангина `#A8431F` для кнопок, охра `#C8912F` для акцентов. Заголовки Playfair Display,
текст Inter — обе гарнитуры с кириллицей.

## Что обязательно заменить до публикации

1. **Портреты преподавателей сгенерированы нейросетью.** Пять лиц в секции «Преподаватели» —
   вымышленные, но подписаны настоящими фамилиями сотрудников школы. Публиковать в таком
   виде нельзя: это выдача чужих сгенерированных лиц за реальных людей. Нужны настоящие фотографии.
2. **Работы учеников тоже сгенерированы.** Восемь рисунков в галерее — не работы учеников
   школы. Имена и сроки под ними («Алина, 3 месяца с нуля») вымышлены. Нужны реальные
   фотографии работ с реальными подписями.
3. **Логотипы вузов** — иконки-заглушки из набора Material Symbols, а не настоящие логотипы.
4. **Отзывы** — три пустых слота с меткой `[отзыв]`, ждут реальных отзывов.
5. **Форма заявки не подключена** — разметка есть, обработчика отправки нет, заявка никуда
   не уходит. Нужен бэкенд или сторонний сервис форм.
6. **Ссылка «политика»** ведёт на ещё не созданную страницу политики обработки персональных
   данных, при том что форма уже собирает телефоны.

## Технические заметки

Страница подключает Tailwind с CDN и Google Fonts — для работы нужен интернет.
Изображения хранятся локально в `img/`, внешних зависимостей по картинкам нет.

Сайт собран через Google Stitch. Учтите особенность: Stitch перерисовывает страницу целиком
и **воссоздаёт по памяти секции, которых нет в текущем промпте**, то есть выдумывает факты
заново. На этой сборке он успел подменить ФИО всех пяти преподавателей, все шесть модулей
программы, четыре шага подготовки и название одного вуза. Порядок обязательной проверки
после каждой итерации описан в `.stitch/SITE.md`, раздел «Известные проблемы текущей сборки».
