# Da Vinci — центр подготовки к вступительным экзаменам

Одностраничный сайт художественной школы Da Vinci (Караганда). Готовим к творческим
вступительным экзаменам на архитектурные и дизайнерские направления в вузах Казахстана
и других стран.

**Статус: черновик.** Сайт рабочий, но часть материалов ещё не заменена на реальные —
см. раздел «Что осталось».

## Состав

```text
index.html      весь сайт одним файлом
privacy.html    политика обработки персональных данных
img/            изображения (10 файлов, 1,2 МБ)
foto/           исходные фотографии школы — не попадают в репозиторий (.gitignore)
.stitch/        рабочие файлы проекта
  SITE.md       конституция проекта: факты, аудитория, карта сайта, бэклог
  DESIGN.md     дизайн-система: палитра, типографика, компоненты
  next-prompt.md задача следующей итерации
  metadata.json идентификаторы проекта и экрана в Stitch
```

## Что на сайте

Тринадцать секций: первый экран, статистика, вузы поступления, боли абитуриента,
программа, «Доводим до поступления», этапы подготовки, преподаватель, студия,
стоимость и расписание, отзывы, вопросы, форма заявки и подвал.

## Как всё устроено технически

Весь сайт — один файл `index.html` плюс папка с изображениями. Сборка не нужна,
файл открывается двойным кликом.

- **Стили Tailwind вшиты** в страницу блоком `<style id="tailwind-inlined">`. Изначально
  они генерировались скриптом с CDN в рантайме: при недоступности CDN вёрстка полностью
  разваливалась. Из этого следует важное ограничение — **дописать новый класс Tailwind
  в разметку нельзя**, для него не окажется правил. Все последующие правки вносятся
  обычным CSS в блоке `<style id="layout-fixes">`, который идёт следом.
- **Форма заявки** не отправляется на сервер, потому что бэкенда нет. Скрипт собирает
  сообщение из полей и открывает чат школы в WhatsApp с подставленным текстом.
  Из этого следует, что заявка нигде не сохраняется, кроме переписки, а сквозная
  аналитика конверсии невозможна.
- **Мобильная версия** — та же страница. Ниже 900px появляются меню-гамбургер
  и липкая нижняя полоса с телефоном и WhatsApp; ниже 640px галерея студии
  превращается в ленту с горизонтальным свайпом.
- **Внешние зависимости** — только Google Fonts: Playfair Display и Inter для текста,
  Material Symbols для иконок. Изображения хранятся локально.

### Дизайн-система «Academic Atelier»

Тёплая бумага `#FAF7F2`, тонированная бумага `#F1EAE0`, графит `#1C1A18`, мягкий графит
`#57514A` для текста, сангина `#A8431F` для кнопок призыва, охра `#C8912F` для акцентов,
карандашный след `#DCD3C6` для границ.

Правило, которое легко нарушить при правках: **на одном экране допустима только одна
кнопка цвета сангины.** Поэтому в липкой мобильной полосе стоит зелёная кнопка WhatsApp,
а не «Записаться».

## Что осталось

1. **Фотографии работ учеников.** Снимки в секции «Внутри нашей студии» показывают
   занятия и мастерскую. Фотографий законченных листов — гипсовая голова, натюрморт,
   портрет, чертёж — среди присланных нет. Это самый убедительный для родителя блок,
   и его стоит собрать отдельно.
2. **Логотипы вузов** — сейчас иконки-заглушки из набора Material Symbols.
   Реальные файлы класть в `img/`, обработка — монохром графитом, цвет при наведении.
   Учтите: логотипы вузов являются товарными знаками, и размещение без разрешения
   формально является их использованием.
3. **Отзывы** — три пустых слота с меткой `[отзыв]`.
4. **Реквизиты в политике** — семь полей выделены пунктиром прямо в тексте
   `privacy.html`: наименование ИП или ТОО, БИН/ИИН, почта, срок хранения, дата
   публикации. Текст — типовой шаблон по Закону РК от 21 мая 2013 года № 94-V
   «О персональных данных и их защите», перед публикацией его должен посмотреть юрист.
