# Da Vinci — центр подготовки к вступительным экзаменам

Одностраничный сайт художественной школы Da Vinci (Караганда). Подготовка к творческим
вступительным экзаменам на архитектурные и дизайнерские направления в вузах Казахстана
и других стран.

**Опубликован:** https://valentin89kz.github.io/DaVinciKrg/

## Состав

```text
index.html      весь сайт одним файлом
privacy.html    политика обработки персональных данных
img/            изображения: работы (18), ученики и студия (20), логотипы вузов (6),
                первый экран, преподаватель
.gitignore      исходники (foto, pupils, logos, Otzyvy) в репозиторий не попадают
.stitch/        рабочие файлы проекта — SITE.md, DESIGN.md, next-prompt.md, metadata.json
```

## Что на странице

Тринадцать секций: первый экран, статистика, вузы поступления, боли абитуриента,
программа, «Доводим до поступления», этапы подготовки, преподаватель, работы учеников,
стоимость и расписание, отзывы, вопросы, форма заявки и подвал.

**Работы учеников** — две бесконечные ленты: сверху 18 работ, снизу 20 кадров с учениками,
держащими свои рисунки, и видами мастерской. Ленты едут навстречу друг другу и встают
на паузу при наведении.

**Отзывы** — управляемая карусель на семь настоящих отзывов с карточки школы в 2GIS.
По одному за раз, полный текст, листание по кругу: стрелки, точки, клавиатура, свайп.
Автопрокрутки нет намеренно — она уводила бы текст из-под глаз читающего.

**Вузы** — реальные логотипы, приведённые к графитовому монохрому.

## Как всё устроено

Весь сайт — один файл `index.html` плюс папка с изображениями. Сборка не нужна,
файл открывается двойным кликом. Общий вес 2,3 МБ.

### Три вещи, на которых легко споткнуться при правках

1. **Новый класс Tailwind дописать в разметку нельзя.** Стили вшиты в страницу
   статически блоком `<style id="tailwind-inlined">` — они были сняты один раз
   с работающей страницы, когда Tailwind ещё генерировал их с CDN. Для класса,
   которого не было в тот момент, правил не окажется, и элемент останется без
   оформления. Все правки вносятся обычным CSS в блоке `<style id="layout-fixes">`,
   который идёт следом.

   На этом уже обожглись: шапка долго стояла без фона, потому что CDN не выдал
   правило для `bg-background/92`. Если что-то выглядит неоформленным — сначала
   сверьте список классов страницы со списком селекторов в стилях.

2. **На одном экране допустима только одна кнопка цвета сангины** `#A8431F`.
   Поэтому в липкой мобильной полосе стоит зелёная кнопка WhatsApp, а не «Записаться».

3. **Форма заявки не отправляется на сервер** — бэкенда нет. Скрипт собирает сообщение
   из полей и открывает чат школы в WhatsApp с подставленным текстом. Отсюда следует,
   что заявка нигде не сохраняется, кроме переписки, а сквозная аналитика конверсии
   невозможна.

### Дизайн-система «Academic Atelier»

Тёплая бумага `#FAF7F2`, тонированная бумага `#F1EAE0`, графит `#1C1A18`, мягкий графит
`#57514A` для текста, сангина `#A8431F` для кнопок призыва, охра `#C8912F` для акцентов,
карандашный след `#DCD3C6` для границ. Заголовки Playfair Display, текст Inter —
обе гарнитуры с кириллицей.

Внешние зависимости — только Google Fonts. Изображения хранятся локально.

### Мобильная версия

Та же страница. Ниже 900px появляются меню-гамбургер и липкая нижняя полоса с телефоном
и WhatsApp. Ниже 640px стрелки карусели отзывов переезжают под слайд, чтобы текст
занимал всю ширину.

## Что осталось

1. **Реквизиты в политике.** Семь полей выделены пунктиром прямо в тексте `privacy.html`:
   наименование ИП или ТОО, БИН/ИИН, почта, срок хранения, дата публикации. Текст —
   типовой шаблон по Закону РК от 21 мая 2013 года № 94-V «О персональных данных
   и их защите», перед публикацией его должен посмотреть юрист.
2. **Логотипы вузов — товарные знаки.** Размещение без письменного разрешения формально
   является их использованием. Практика для частных школ обычная, но риск существует;
   безопасная альтернатива — оставить текстовые названия и цифры.
3. **`thanks.html` и `gallery.html`** — в планах, не сделаны. Страница благодарности
   пока недостижима: после отправки заявки человек уходит в мессенджер и на сайт
   не возвращается.

## Публикация

GitHub Pages, ветка `main`, папка `/ (root)`. После пуша сборка занимает одну-две минуты.

Браузер агрессивно кеширует страницу. На компьютере обновляйте через **Ctrl+F5**,
на телефоне проще открыть адрес с добавкой в конце: `?2`, `?3` и так далее.
